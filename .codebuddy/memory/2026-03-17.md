# 2026-03-17 — Frontend UI/UX Optimization (ui-ux-pro-max)

## What was done
Used ui-ux-pro-max skill to perform a comprehensive UI/UX audit and optimization of the whoami frontend (Nuxt 4 + Vue 3 + Tailwind CSS).

### Changes made across 14 files:

**Global CSS (`main.css`)**
- Added `prefers-reduced-motion` support (disables animations for users who prefer reduced motion)
- Added accessible `:focus-visible` styles (2px accent ring, 2px offset)
- Added `:focus:not(:focus-visible)` to remove outline for mouse users
- Added `cursor: pointer` globally for `a` and `button` elements
- Added `cursor: not-allowed` for disabled buttons
- Added `.skip-link` CSS for keyboard-only skip navigation

**Tailwind Config (`tailwind.config.ts`)**
- Added 3 new animations: `shimmer`, `slide-in-right`, `press`
- These support skeleton loading, slide-in effects, and button press feedback

**Layout (`default.vue`)**
- Added skip link `<a href="#main-content">` for keyboard navigation
- Added `id="main-content"` to `<main>` element
- Added `aria-expanded`, `aria-haspopup`, `role="menu"`, `role="menuitem"` to user dropdown
- Added icons to dropdown menu items (Dashboard, Logout)
- Added divider between dropdown items
- Added chevron rotation animation on dropdown open
- Footer links wrapped in `<nav aria-label="Footer navigation">`
- Footer GitHub link now has inline icon
- Logo `img` marked `aria-hidden="true"` (decorative, text label is the accessible name)

**HeroSection**
- Added `aria-label="Hero"` to section
- Background decorative elements marked `aria-hidden="true"`
- CTA button gets `active:scale-[0.97]` press feedback
- Badge marked with `role="status"`
- Subtitle gets `leading-relaxed` for better readability

**FeaturesSection & FlowAnimation**
- Cards get enhanced hover: `-translate-y-1.5`, `shadow-lg shadow-accent/5`, softer border transition
- Sections get `aria-label` for screen readers
- Subtitles get `leading-relaxed`

**InstallGuide**
- Image gets `width/height` attributes and `aspect-ratio: 16/9` to prevent CLS
- Image uses `object-cover` and explicit dimensions

**Dashboard**
- Loading state: replaced single spinner with skeleton cards (2 placeholder cards with animated pulse)
- Empty state: improved with centered icon + message (matches ProfileDialog pattern)
- Sections get `aria-label`
- Decorative elements marked `aria-hidden="true"`
- Buttons get `active:scale-[0.97]` or `active:scale-[0.99]`

**Login page**
- Background marked `aria-hidden="true"`
- AI context banner gets `role="alert"`
- Logo img marked `aria-hidden="true"`
- Subtitle gets `leading-relaxed`

**OAuthButtons**
- Wrapper gets `role="group" aria-label="Sign in options"`
- Each button gets `aria-label` (e.g., "Continue with GitHub")
- SVG icons marked `aria-hidden="true"`
- All buttons get `active:scale-[0.98]` press feedback

**AccessKeyCard**
- Card gets `role="article"` and `:aria-label`
- Status badges get `role="status"`
- Decorative dots marked `aria-hidden="true"`
- Unlink button gets descriptive `:aria-label` with agent name
- Desktop unlink button also responds to `focus-visible:opacity-100` (keyboard accessible)

**ConfirmDialog**
- Dialog gets `role="alertdialog"`, `aria-modal="true"`, `:aria-label`
- SVG icons marked `aria-hidden="true"`
- Message text gets `leading-relaxed`
- Buttons get `active:scale-[0.97]`

**ProfileDialog**
- Dialog gets `role="dialog"`, `aria-modal="true"`, `:aria-label`
- All action buttons get `active:scale-[0.97]`
- Disabled save button gets `disabled:active:scale-100` (no press effect when disabled)
- SVG icons marked `aria-hidden="true"`

**CopyBlock**
- Both prominent and inline copy buttons get `active:scale-[0.95]`
- Buttons get `:aria-label` for accessibility

**ThemeSwitcher**
- Button gets `:aria-label` and `:aria-expanded`

**LanguageSwitcher**
- Button gets locale-aware `:aria-label`
